Formula sheet

The identities and equations that show up most in middle school, high school, and first-year college work.

Algebra

Linear equation

ax + b = 0 → x = −b / a

Slope-intercept form: y = mx + b, where m is slope and b is the y-intercept.

Quadratic formula

x = (−b ± √(b² − 4ac)) / 2a

Discriminant D = b² − 4ac. D > 0 two real roots, D = 0 one root, D < 0 complex roots.

Exponent rules

aᵐ · aⁿ = aᵐ⁺ⁿ   (aᵐ)ⁿ = aᵐⁿ   a⁻ⁿ = 1/aⁿ

a⁰ = 1 (a ≠ 0). √a = a^(1/2). Change of base: log_b a = ln a / ln b.

Logarithms

log(ab) = log a + log b   log(a/b) = log a − log b

log(aⁿ) = n log a. Natural log ln is log base e. Common log is base 10.

Geometry

Areas

Rectangle: lw. Triangle: ½bh. Circle: πr². Trapezoid: ½(a+b)h. Parallelogram: bh.

Volumes

Box: lwh. Cylinder: πr²h. Sphere: ⁴⁄₃πr³. Cone: ⅓πr²h. Pyramid: ⅓Bh.

Pythagorean theorem

a² + b² = c²

Distance between (x₁,y₁) and (x₂,y₂): √((x₂−x₁)² + (y₂−y₁)²).

Circle facts

Circumference C = 2πr. Arc length = θr (θ in radians). Sector area = ½r²θ.

Trigonometry

SOH-CAH-TOA

sin θ = opp/hyp   cos θ = adj/hyp   tan θ = opp/adj

csc = 1/sin, sec = 1/cos, cot = 1/tan.

Identities

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ. sin(2θ) = 2 sinθ cosθ. cos(2θ) = cos²θ − sin²θ.

Law of sines / cosines

a/sin A = b/sin B = c/sin C

c² = a² + b² − 2ab cos C. Use this for any triangle, not just right triangles.

Radians

180° = π rad. 1 rad ≈ 57.3°. Full circle = 2π rad = 360°. Unit circle: (cos θ, sin θ).

Physics

Motion

v = v₀ + at   s = v₀t + ½at²   v² = v₀² + 2as

Average speed = distance / time. Velocity is a vector; speed is not.

Newton and energy

F = ma   W = Fd cosθ   KE = ½mv²   PE = mgh

Momentum p = mv. Impulse = Δp = FΔt. Power P = W/t = Fv.

Waves and electricity

v = fλ   V = IR   P = IV = I²R

Series resistors add. Parallel: 1/R = 1/R₁ + 1/R₂. Coulomb: F = kq₁q₂ / r².

Gases and heat

PV = nRT   Q = mcΔT

STP is 0 °C and 1 atm. Specific heat of water is 4.184 J/g·°C.

Chemistry

Moles

n = m / M   n = N / NA   n = C · V

NA = 6.022 × 10²³ mol⁻¹. Molarity C is moles per liter of solution.

Stoichiometry

Balance the equation. Convert given grams → moles → mole ratio → desired grams. Limiting reactant is the one that runs out first.

pH

pH = −log[H⁺]   pOH = −log[OH⁻]   pH + pOH = 14

Acids pH < 7, bases pH > 7. Strong acids fully dissociate in water.

Bonding quick read

Ionic: metal + nonmetal, electrons transferred. Covalent: shared electrons. Metallic: delocalized electrons. Polar molecules have uneven charge.

How Helix Desk works

Scientific mode

Adds square root, square, reciprocal, and π. Use the periodic table “Use mass” button to drop an atomic mass into the display.
